# Changelog

## 0.2.0

Entry-point accuracy and a new launch gate, from a month of daily use on a production Next.js app.

- Next.js conventional files are entries at any depth: `not-found`, `robots`, `sitemap`, `manifest`, `default`, `global-error`, `opengraph-image`, `twitter-image`, `icon`, `apple-icon`. They were previously reported as orphans because no route imports them.
- A deep barrel `index.ts` is no longer an entry point. Only the repo root and one level down (`src/index.ts`) qualify. Counting deeper barrels as entries had hidden 13 dead files behind two barrels nobody imported.
- Skill, Mode 3 (audit): two rules from a sweep that removed 52 files. An unimported barrel is itself an orphan and hides its members, and the map must be rebuilt before reporting unused dependencies, because a package only the deleted files imported only shows up after the rebuild.
- Skill, Mode 6 (new): a marketing-claims gate to run before any production launch in a repo with a public site. Four drift classes (tier and price, billing flow, capability in both directions, legal surface), checked against the enforcing code with `--find` and `--trace`, ranked and blocking.
- Skill: a short section on applying the same map-then-judge pattern to artifacts other than code, with the two rules that carried over (the index must be generated by the producing tool, and every detector needs a self-test pinned to real defects).
- Tests for the new entry rules.
